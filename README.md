# 📦 SKSystem Client App (Flutter)

A Flutter-based mobile application for customers of SKSystem, a delivery company. Built with Dart, the application provides a foundation for customer-facing delivery services and communication with backend APIs.

🚀 **Features**

- 📱 Cross-platform Flutter application
- 🔌 HTTP API communication
- 🔄 State management using GetX
- 💾 Local preferences and data storage
- 📄 PDF document viewing support
- 🔔 Toast notifications and interactive UI components
- 🌐 WebSocket communication support
- 🤖 Android platform support
- 🍎 iOS platform configuration
- 💻 Web and desktop platform configurations

⚙️ **Installation**

This project requires Flutter SDK, Dart, Git, and a compatible development environment.

🧱 **1. Clone the repository**

```bash
git clone https://github.com/nourddine20/Sksystem-Client-App.git
cd Sksystem-Client-App
```

🔧 **2. Install dependencies**

```bash
flutter pub get
```

🔑 **3. Configure the application**

Review the application configuration and source code for required backend API URLs, environment variables, and other settings.

Make sure the backend services are available if required.

🚀 **4. Run the application**

Check connected devices:

```bash
flutter devices
```

Start the application:

```bash
flutter run
```

📱 **5. Build for Android**

Generate a release APK:

```bash
flutter build apk --release
```

For an Android App Bundle:

```bash
flutter build appbundle --release
```

🧪 **Testing**

Analyze the project:

```bash
flutter analyze
```

Run automated tests:

```bash
flutter test
```
